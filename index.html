⚡ ElectroLab

AC & DC Virtual Circuit Construction Laboratory

How to use

  1. Drag an apparatus from the left toolbox.
  2. Move the apparatus anywhere in the simulator.
  3. Click an apparatus to select it.
  4. Drag the ↻ handle to rotate it.
  5. Drag a wire endpoint to resize or connect it.
  6. Drag the middle of a wire to move it.
  7. Connected wire ends snap to terminals.
  8. Use the Remove button or Delete key to remove it.
  9. Press START SIMULATION.

Keyboard

Delete / Backspace → Remove selected
Space → Start / pause simulation
R → Reset simulation
Q → Rotate left
E → Rotate right
Escape → Deselect
